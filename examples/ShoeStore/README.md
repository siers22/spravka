# «Чудо Обувь» — учебный пример для Windows

КИМ 09.02.07-2-2027, квалификация «Программист». .NET 10 / C# / Razor Pages. БД — PostgreSQL или Microsoft SQL Server. Каталог, скидки по предыдущему календарному месяцу, вход только по логину, комбинированные фильтры, подробности, корзина, транзакционное оформление, управление заказами по ролям.

## Запуск

Подготовьте .NET 10 SDK и выбранную СУБД заранее. В PowerShell из папки ShoeStore:

```powershell
dotnet restore
```

Создайте пустую БД `shoe_store` в pgAdmin или SSMS. Выполните `sql/postgres-schema.sql` или `sql/mssql-schema.sql` в этой базе. Измените `appsettings.json`: Database:Provider = Postgres / SqlServer; строка подключения должна указывать ваш сервер, экземпляр, порт и пароль. Для SQL Server пример использует Windows Authentication.

```powershell
dotnet run -- --import
dotnet run --urls http://localhost:5090
```

Откройте http://localhost:5090. Не запускайте --import повторно. Альтернативный путь — выполнить `…-complete.sql` (схема и данные) в пустой базе и сразу запустить приложение, **без --import**.

Вход по исходным логинам: `isivanov` — Admin, `papetrov` — Manager, `asidorova` — User. Пароль по ТЗ не нужен. ФИО справа сверху. Гостю доступен каталог, оформление требует входа. Staff может выбрать клиента в корзине. Обычный пользователь создаёт только собственный заказ. /Orders доступен только Manager/Admin; изменение даты и удаление отдельной строки — только Admin.

## Импорт и важные особенности

Исходники: Data/*.xlsx. 31 модель, 92 позиции по размерам, 35 размеров (включая половинки), 20 пользователей, 10 заказов и 30 строк. Размер — decimal(3,1), деньги — decimal(18,2). XLSX содержит текстовые дробные размеры с точкой; C# разбирает их явно в invariant culture.

ImportService нормализует пробелы, включая NBSP. Сокращённое «Черные туфли в классическом стиле» сопоставлено с полной моделью «Черные туфли в классическом стиле — база для деловых образов» производителя Барбари. Это явное решение для данного образца. Остатки в Stock_Items уже доступные: исторические заказы повторно не вычитаются.

Скидка 25% относится к модели по всем её размерам. Проверяем [первое число прошлого месяца, первое число текущего). Отсутствие заказов в этом периоде даёт цену base_price × 0.75. «Много» >5, «мало» ≤5; фон #ff8080 при сумме ≤3. Неизвестное изображение заменяется picture.png. Цвета и Calibri — по исходному руководству.

Архивные заказы — апрель/май 2026. Для воспроизводимой тренировки можно добавить в корень appsettings.json `"CalculationDate": "2026-05-15"`. Тогда проверяется апрель. Удалите поле перед сдачей: без него используется текущая дата Windows.

Корзина хранится в Session, до подтверждения склад не меняет. При подтверждении сервер заново рассчитывает цену, проверяет остаток условным UPDATE и сохраняет заказ со всеми строками в Serializable-транзакции. Сбой любой строки откатывает всё. Цена сохраняется в строке заказа. Отмена черновика только очищает корзину. Удаление подтверждённого заказа/строки возвращает пары на склад в транзакции; пустая шапка удаляется. Все формы изменения защищены anti-forgery. Прямые серверные запросы проверяют роль.

## Сдача и проверка

Проверяйте сначала импорт, затем границы скидок и остатков, вход трёх ролей, сочетание фильтров, заказ из двух моделей, недостаточный остаток, отмену, удаление и редактирование даты. Проверьте сохранение после перезапуска. Исходный полный SQL содержит начальные данные; после изменения заказов экспортируйте актуальную БД со схемой и данными (pg_dump --inserts либо SSMS Generate Scripts → Schema and data). Восстановите в отдельную пустую БД.

Для Windows-публикации:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o .\publish
.\publish\ShoeStore.exe --urls http://localhost:5090
```

Runtime-пакеты для публикации восстановите заранее. Проверяйте публикацию на Windows; база запускается отдельно. Приложение не создаёт БД при обычном старте. Если порт занят, замените 5090 на 5091. Остановить — Ctrl+C.

В репозиторий площадки передайте структуру файлов, а не учебный ZIP: исходники, публикацию, SQL с данными, ER-PDF, алгоритм, графику и README. `shoe-er.drawio` находится рядом с папкой проекта в учебном архиве: экспортируйте его в PDF редактором диаграмм. Локальные логины, пароль БД и имя экземпляра настройте под площадку.

Проверено: сборка .NET 10 и работа с PostgreSQL. SQL Server использует отдельную Unicode-схему и Microsoft.Data.SqlClient; запуск с живым SQL Server и Windows-публикацию требуется проверить на Windows.
