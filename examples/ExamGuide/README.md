# Учебный пример под Windows: Razor Pages + C#

Это пример решения образца КИМ 09.02.07-5-2027. Использует .NET 10 SDK, PostgreSQL либо SQL Server. Сайт-методичка отдельно написан на Vue.

## Подготовка

1. Установите .NET 10 **SDK**, не только Runtime. В PowerShell проверьте `dotnet --list-sdks`.
2. Установите одну БД: PostgreSQL + pgAdmin либо SQL Server Express + SSMS. Запишите имя экземпляра, пароль и порт. LocalDB не равен SQLEXPRESS: для LocalDB строка начинается `Server=(localdb)\MSSQLLocalDB`.
3. В pgAdmin/SSMS создайте пустую базу `exam_demo`. В SSMS выберите эту базу в списке над редактором.
4. Запустите `sql/postgres-schema.sql` либо `sql/mssql-schema.sql` **целиком один раз**. Затем соответствующий `*-seed.sql`. Скрипты создания таблиц не повторяйте в существующей базе.
5. В `appsettings.json` поставьте `Database:Provider` = `Postgres` либо `SqlServer`. Замените CHANGE_ME своим паролем PostgreSQL. Для SQL Server используется Windows Authentication. Для другого экземпляра исправьте Server.
6. В PowerShell перейдите в папку, в которой лежит ExamGuide.csproj:

```powershell
cd C:\Exam\ExamGuide
dotnet restore
dotnet run -- --seed
dotnet run --urls http://localhost:5080
```

Импорт сохранит шесть записей из исходного JSON без изменения ведущих нулей ID. Запись DEMO00001 — дополнительный заказчик из XLSX. Повторный seed не дублирует существующие ID.

Откройте http://localhost:5080/Login. admin / Admin123!, user / User123! — учебные аккаунты. Нажмите на два фрагмента пазла для их обмена. Верный порядок исходных файлов: 1.png, 2.png, 3.png, 4.png (слева направо, сверху вниз). Пазл выдаётся сервером в перемешанном порядке. Три неверные отправки формы для существующего логина блокируют запись. Блокировка сохраняется после перезапуска. Сброс — в /Admin.

## Проверка

- `/notes` возвращает JSON из настоящей БД: id, title_user, content, formatted_date.
- `/notes?user_id=abc` → 400; `/notes?user_id=2147483647` → 200 и [].
- Остановите службу выбранной БД, но оставьте приложение работающим. `/notes` → 500 с JSON error. Запустите БД снова.
- В Postman импортируйте ../notes.postman_collection.json. Папку 500 запускайте отдельно с отключённой БД. Проверьте переменную baseUrl.
- `sql/*-cost.sql` возвращает 14374.28 для двух столов при использовании норм и цен XLSX. Это нормативный расчёт: он НЕ повторяет противоречивый итог 11448.12 из «Расчёт стоимости.xlsx». Цена продажи 26828 со скидкой — другой показатель.
- API доступен без авторизации, потому что приложение 2 не требует защиты GET /notes. Администрирование защищено серверной политикой роли и cookie; формы Razor используют antiforgery.

## Ограничения учебного варианта

Цены без истории, одна текущая спецификация на продукт, ручные ID производственных справочников; таблица users выделяет ID транзакционно. Сопоставление разных кодов одного стола принято по одинаковому названию и должно быть подтверждено для нового варианта. Норму операции трактуем как множитель цены и количества; единица «упаковки» требует уточнения у заказчика. В исходном JSON inn допускает пустую строку и нетипичную длину: импорт не исправляет оригинал. Для экзамена подготовьте SDK, NuGet-пакеты и редактор заранее: в КИМ предусмотрена локальная сеть без Интернета. Выбор ПО площадки надо учитывать.
