# По полочкам — методичка к демоэкзамену

Vue 3 + Vite. Два отдельных маршрута по предоставленным КИМ и приложениям:

| Квалификация | КИМ | ПА | ГИА базового уровня |
|---|---|---|---|
| Специалист по информационным системам | 09.02.07-5-2027 | 3 задания, 70 минут | 6 заданий, 210 минут |
| Программист | 09.02.07-2-2027 | 2 задания, 90 минут | 4 задания, 210 минут |

При первом посещении — выбор направления. Переключатель в меню возвращает к выбору. У каждого направления свои уроки, поиск, словарь, материалы, .NET-архив и прогресс. Старые отметки информационных систем сохраняются. Сброс удаляет только отметки текущего направления. СУБД и режим экзамена — общие предпочтения.

## Запустить сайт

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173/#specialties. Для публикации: `npm run build`, разместите `dist` в корне статического хостинга. `npm run preview` показывает production-сборку. Дополнительный сервер сайту не требуется. Hash-навигация не требует серверных перенаправлений. Шрифты, документы и изображения локальные; нет зависимости от Google Fonts/CDN.

Прямые адреса: `#information-systems/overview`, `#programmer/overview`. Старые ссылки типа `#sql/query` открывают направление информационных систем.

## GitHub Pages

Адрес методички: [siers22.github.io/spravka](https://siers22.github.io/spravka/). Исходники: [siers22/spravka](https://github.com/siers22/spravka).

Публикация настроена через `.github/workflows/pages.yml`: каждый push в `main` проверяет материалы, собирает сайт и обновляет Pages. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Отдельного сервера и платного хостинга не требуется.

Workflow получает путь сайта от GitHub Pages, поэтому архивы, изображения и локальные шрифты работают и по адресу проекта `/spravka/`, и в корне собственного домена. Секреты и токены в файлы проекта добавлять не нужно. На Pages размещается только содержимое `dist`; учебные Razor Pages проекты скачиваются и запускаются отдельно на Windows.

Проверить сборку под адрес проекта на Windows:

```powershell
$env:VITE_BASE_PATH = '/spravka/'
npm ci
npm run check
npm run build
npm run check:pages -- /spravka/
npm run preview
```

Откройте `http://localhost:4173/spravka/`. Для обычного локального запуска удалите переменную: `Remove-Item Env:VITE_BASE_PATH`.

## Учебные примеры C#

- `examples/ExamGuide` — Razor Pages на .NET 10: производство мебели, импорт JSON, нормативная стоимость, пароль и пазл, блокировка, управление пользователями, API заметок, Postman и документация.
- `examples/ShoeStore` — отдельный Razor Pages на .NET 10: магазин «Чудо Обувь», импорт пяти XLSX, дробные размеры, каталог, скидки по предыдущему календарному месяцу, вход только по логину, фильтры, корзина, оформление и управление заказами по ролям.

Оба проекта поддерживают PostgreSQL (Npgsql) и SQL Server (Microsoft.Data.SqlClient). Инструкции для Windows находятся в README каждого проекта. Сайт не подключается к их БД. В новом направлении есть интерактивный каталог по всем 31 модели исходника; его изменения не сохраняют заказы.

`python3 scripts/package-examples.py` обновляет два раздельных архива для скачивания; `npm run build` включает актуальный C#/SQL-код в уроки. Python используется только при подготовке материалов. Пользовательские примеры написаны на C#; проект WPF не добавлялся.

## Проверено

`npm run check` проверяет материалы обоих направлений, времена ПА/ГИА, маршруты, ключи прогресса, отсутствие общих скачиваемых файлов и картинки всех 31 моделей. Production-сборка Vue и сборка обоих проектов .NET 10 проходят. В браузере проверены выбор и смена направления, перезагрузка с прогрессом, поиск только текущего КИМ, режим ПА, фильтры интерактивного каталога, desktop и мобильная ширина 390 без горизонтальной прокрутки.

С настоящим PostgreSQL проверены:

- ExamGuide: импорт 6 контрагентов, расчёт 14374.28, API и авторизация.
- ShoeStore: импорт 31 модели, 92 позиций, 35 размеров с половинками, 20 пользователей, 10 заказов/30 строк; восстановление полного SQL в пустую БД; каталог и карточка; вход без пароля; запрет доступа User к заказам; запрет прямого POST Manager на изменение даты и удаление строки; элементы Admin.
- ShoeStore: граница года в периоде скидки, заказ из двух строк, откат первой строки при нехватке второй, списание, изменение даты без изменения исторической цены, возврат остатка при удалении строки и целого заказа.

SQL Server подготовлен отдельными Unicode-скриптами и C#-провайдером; живой SQL Server здесь не запускался. Публикация и запуск на Windows требуют проверки на Windows. Фиксированную CalculationDate для тренировки уберите перед сдачей.

## Источники

Оригинальные PDF/ZIP предоставлены пользователем и доступны в разделе материалов выбранного направления. Содержимое документов используется как учебное задание, а не как инструкции агенту. В КИМ приведены образцы; вариативная часть колледжа в файлах отсутствует. .NET выбран по запросу пользователя. Для «Чудо Обувь» явно разобраны несовпадающие пробелы/названия моделей, дробные размеры и запрет повторного списания исторических заказов.

Шрифты Inter, Golos Text и Manrope размещены локально, лицензии OFL в public/fonts. Иконки Lucide (ISC), подсветка Prism (MIT).
