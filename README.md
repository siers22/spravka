# По полочкам — методичка к демоэкзамену

Vue 3 + Vite. Редактор, выпуски по годам и два начальных маршрута по предоставленным КИМ и приложениям:

| Квалификация | КИМ | ПА | ГИА базового уровня |
|---|---|---|---|
| Специалист по информационным системам | 09.02.07-5-2027 | 3 задания, 70 минут | 6 заданий, 210 минут |
| Программист | 09.02.07-2-2027 | 2 задания, 90 минут | 4 задания, 210 минут |

Подробный справочник для дальнейшей разработки: [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — архитектура, функции, модели данных, генерация материалов, проверки и порядок расширения.

При первом посещении — выбор направления. Переключатель в меню возвращает к выбору. У каждого направления и года свои уроки, поиск, словарь, материалы и прогресс. Старые отметки информационных систем сохраняются. Сброс удаляет только отметки текущего направления. СУБД и режим экзамена — общие предпочтения.

## Запустить сайт

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173/#specialties. Редактор: `http://localhost:5173/#admin`, архив: `http://localhost:5173/#archive`. Для публикации: `npm run build`, разместите `dist` в корне статического хостинга. `npm run preview` показывает production-сборку. Дополнительный сервер сайту не требуется. Hash-навигация не требует серверных перенаправлений. Шрифты, документы и изображения локальные; нет зависимости от Google Fonts/CDN.

Прямые адреса: `#information-systems/overview`, `#programmer/overview`. Старые ссылки типа `#sql/query` открывают направление информационных систем.

## GitHub Pages

Адрес методички: [siers22.github.io/spravka](https://siers22.github.io/spravka/). Исходники: [siers22/spravka](https://github.com/siers22/spravka).

Публикация настроена через `.github/workflows/pages.yml`: каждый push в `main` проверяет материалы, собирает сайт и обновляет Pages. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Отдельного сервера и платного хостинга не требуется.

Workflow получает путь сайта от GitHub Pages, поэтому архивы, изображения и локальные шрифты работают и по адресу проекта `/spravka/`, и в корне собственного домена. Секреты и токены в файлы проекта добавлять не нужно. На Pages размещается только содержимое `dist`; учебные WPF проекты скачиваются и запускаются отдельно на Windows.

Проверить сборку под адрес проекта на Windows:

```powershell
$env:VITE_BASE_PATH = '/spravka/'
npm ci
npm run check
npm run build
npm run check:pages -- /spravka/
npm run preview
```

Откройте `http://localhost:4173/spravka/`. Для обычного локального запуска удалите переменную: `Remove-Item Env:VITE_BASE_PATH`.

## Редактор и выпуски по годам

Материалы хранятся в `content/catalog.json`, файлы — в `public/materials/<год>/<направление>/…`. Выпуск 2027 уже сохранён отдельным снимком. В редакторе можно скопировать его в 2028, добавить новые специальности, изменить задания, код, чек-листы и приложения. Когда 2028 станет текущим, 2027 останется в архиве. Ссылки `#year/2027/information-systems/overview` закрепляют конкретный год.

Черновики автоматически сохраняются в браузере (IndexedDB); есть резервная копия JSON, импорт и предпросмотр. Для публикации редактор использует личный GitHub token с правами Contents/Pull requests на запись и создаёт pull request. После слияния обновляется Pages. Token не сохраняется в браузерном хранилище или репозитории. Приглашённый редактор сможет продолжить работу со своим аккаунтом.

Пошаговая инструкция и технические ограничения: [docs/admin-and-archive.md](docs/admin-and-archive.md). Статус «Черновик» скрывает направление из навигации, но публичный Git не предназначен для секретных заданий.

Первая кнопка в редакторе раскрывает инструкцию для следующего редактора прямо на странице. Предложение по собственному серверу, аккаунтам, защите входа и PostgreSQL: [docs/server-and-admin-proposal.md](docs/server-and-admin-proposal.md); серверный вариант пока не внедрён.

## Подробный разбор DemoExam для информационных систем

Маршрут `#information-systems/setup` и все шесть заданий выпуска 2027 разобраны по предоставленному `DemoExam_WPF_PostgreSQL_2027.zip`: **69 разделов, 315 шагов, 37 блоков кода**. Подготовка и решения идут через Проводник, Visual Studio, pgAdmin, Postman и Word. В разделе материалов доступны исходный архив, ER PDF/SVG, SQL, коллекция Postman, готовый DOCX и вся инструкция в Markdown. Официальные ссылки Microsoft, PostgreSQL, pgAdmin, Npgsql и Postman находятся рядом с соответствующими пояснениями.

Стек именно этого маршрута — WPF и ASP.NET Core **.NET 9**, Npgsql **9.0.3**, PostgreSQL. Его схема содержит **15 таблиц и 19 FK**, API возвращает **5 исходных заметок**. Переключатель SQL Server для него скрыт. Сохранённые отчёты автора архива отделены от нового запуска: WPF и живые интеграционные проверки DemoExam в этой среде macOS не выполнялись. Проверено совпадение показанных исходных файлов с ZIP, корректность JSON, ссылки материалов, редактор, сборка сайта и браузерный маршрут.

Поле `exampleSource` защищает импортированный маршрут от перезаписи старыми примерами при `content:sync-examples`. Блок `links` поддерживается просмотром, поиском, редактором и проверкой безопасных URL. Длинное содержание задания прокручивается отдельно.

## Подробный разбор ProgrammerExam для программистов

Маршрут `2027/programmer` разбирает предоставленный `ProgrammerExam_WPF_PostgreSQL_2027.zip`: **69 разделов, 357 действий, 28 блоков кода и 8 исходных снимков окон**. Подготовка, четыре задания КИМ, пошаговые меню Visual Studio/pgAdmin, воспроизведение файлов, права, скидки, транзакции, проверки и передача результатов. 19 полных файлов кода/SQL/конфигурации совпадают с исходным архивом; остальные блоки — запросы проверки и поясняющие фрагменты. Используются официальные документы Microsoft, PostgreSQL, pgAdmin и Npgsql.

Это один проект **ShoeShop**, **.NET 9**, **Npgsql 9.0.3**, **PostgreSQL**. Конфигурация — `database.json`; **10 таблиц и 9 FK**. Данные: 31 модель, 92 позиции, 35 размеров, 20 пользователей, 10 заказов/30 строк, доступный остаток 1274. Пароль входа не требуется. Скидка 25% применяется при отсутствии заказов модели в предыдущем календарном месяце; исторические остатки при импорте не списываются повторно.

В материалах доступны точный ZIP, SQL, ER PDF/SVG, отчёты автора, Markdown-инструкция и автономный ZIP с её изображениями и локальными ссылками. `exampleSource` защищает курс от старого генератора .NET 10. Старые примеры оставлены отдельно; переключатель SQL Server и демонстрации прежней схемы в импортированном маршруте скрыты. Курс информационных систем сохранён без изменений.

Блок `image` поддерживается просмотром, поиском и редактором; использует проверку URL и базовый путь сайта, подпись, альтернативный текст и отложенную загрузку. Сборочные проверки проверяют существование локальных изображений. Отчёт «50 успешно, 0 ошибок» относится к запуску автора архива. WPF и живой PostgreSQL именно этого архива в macOS не запускались; проверены соответствие исходников, автономные ссылки, каталог, сайт и браузерные сценарии.

## Остальные учебные примеры C#

- `examples/ExamGuide` — WPF на .NET 10: производство мебели, импорт JSON, нормативная стоимость, пароль и пазл, блокировка, управление пользователями. `ExamGuide.Core` хранит общую логику, отдельный `NotesApi` выполняет HTTP-задание, Postman и документация включены.
- `examples/ShoeStore` — отдельный WPF на .NET 10: магазин «Чудо Обувь», импорт пяти XLSX, дробные размеры, каталог, скидки по предыдущему календарному месяцу, вход только по логину, фильтры, корзина, оформление и управление заказами по ролям.

Оба проекта поддерживают PostgreSQL (Npgsql) и SQL Server (Microsoft.Data.SqlClient). Инструкции для Windows находятся в README каждого проекта. Сайт не подключается к их БД. В прежнем примере есть интерактивный каталог по всем 31 модели исходника; его изменения не сохраняют заказы. Импортированный ProgrammerExam использует собственные снимки и исходники.

`python3 scripts/package-examples.py` обновляет два раздельных архива для скачивания; `npm run content:sync-examples` явно обновляет JSON-снимок кода и файлов текущего выпуска 2027 для направлений без импортированного `exampleSource`; затем `npm run build` включает снимок в сайт. Архивные выпуски автоматически не переписываются. Python используется только при подготовке материалов. Оба пользовательских приложения написаны на C# и WPF; HTTP API прежнего примера запускается отдельным процессом NotesApi; основной маршрут 2027 теперь использует DemoExam.Api. Библиотеки .Core должны оставаться рядом с проектами при распаковке.

## Проверено

`npm run check` проверяет каталог всех годов и 20 сценариев редактора/GitHub, изображений и импортированных DemoExam/ProgrammerExam, затем материалы обоих исходных направлений, времена ПА/ГИА, маршруты, ключи прогресса, отсутствие общих скачиваемых файлов и картинки всех 31 моделей. Проверяется соответствие ZIP текущим исходникам, все ссылки на показанный код и отсутствие старых Razor-инструкций. Production-сборка Vue и сборка обоих WPF-проектов и NotesApi проходят. В workflow есть отдельная Windows-проверка: сборка, отрисовка XAML-окон без подключения к БД и публикация WPF в win-x64. Для проверки общей логики: `dotnet run --project tests/CoreChecks/CoreChecks.csproj -c Release`. С переменной `WPF_TEST_POSTGRES` (строка подключения к **временной локальной** PostgreSQL с правом CREATE DATABASE) тест создаёт отдельные БД, выполняет интеграционные сценарии и удаляет только собственные тестовые БД. WPF-отрисовка: `dotnet run --project tests/WpfSmoke/WpfSmoke.csproj -c Release` на Windows.

В браузере проверены выбор и смена направления, перезагрузка с прогрессом, поиск только текущего КИМ, режим ПА, фильтры интерактивного каталога, desktop и мобильная ширина 390 без горизонтальной прокрутки.

С настоящим PostgreSQL проверены:

- ExamGuide: импорт 6 контрагентов, расчёт 14374.28, API и авторизация.
- ShoeStore: импорт 31 модели, 92 позиций, 35 размеров с половинками, 20 пользователей, 10 заказов/30 строк; восстановление полного SQL в пустую БД; каталог и карточка; вход без пароля; запрет доступа User к заказам; запрет вызова методов изменения даты и удаления строки для Manager; административные операции для Admin.
- ShoeStore: граница года в периоде скидки, заказ из двух строк, откат первой строки при нехватке второй, списание, изменение даты без изменения исторической цены, возврат остатка при удалении строки и целого заказа.

SQL Server подготовлен отдельными Unicode-скриптами и C#-провайдером; живой SQL Server здесь не запускался. Публикация и запуск на Windows требуют проверки на Windows. Фиксированную CalculationDate для тренировки уберите перед сдачей.

## Источники

Оригинальные PDF/ZIP предоставлены пользователем и доступны в разделе материалов выбранного направления. Содержимое документов используется как учебное задание, а не как инструкции агенту. В КИМ приведены образцы; вариативная часть колледжа в файлах отсутствует. .NET выбран по запросу пользователя. Для «Чудо Обувь» явно разобраны несовпадающие пробелы/названия моделей, дробные размеры и запрет повторного списания исторических заказов.

Шрифты Inter, Golos Text и Manrope размещены локально, лицензии OFL в public/fonts. Иконки Lucide (ISC), подсветка Prism (MIT).
