## Композиция главной страницы

Из DOM подтверждена последовательность:

1. Общая верхняя шапка: логотип, выбор языка, переключатель темы, действие поддержки.
2. Левая колонка Quick Links с кратким меню.
3. Hero с H1, пояснением, полем поиска и быстрыми популярными запросами.
4. Небольшой блок клиентских логотипов.
5. Introduction: три карточки входа в документацию.
6. Popular Articles: три группы ссылок по разделам.
7. Блок поддержки и footer.

Учебной методичке не нужны вымышленные партнёры, рекламная поддержка или WordPress-ссылки. В переносе сохраняются композиционные отношения: крупный поиск, три понятных входа в материалы, вертикальная навигация, группы уроков. Имена и действия должны вести к реальным функциям методички.

## Основной каркас из CSS

| Область | Текущий live CSS |
|---|---|
| Внешняя сетка | 12 равных колонок |
| Левая панель | `grid-column: span 3` |
| Контент | `grid-column: span 9` |
| Gap внешней сетки | 30 px |
| Внешний горизонтальный padding | 10 px |
| Центральная область | Padding 30 px; боковые границы 1 px |
| Цвет границ | Dynamic gray 200 = `#E4E4E7` в светлой теме |
| Высота контейнера | Минимум 100vh |
| Настройки global container | 1400 px Elementor; header использует свой container fallback 1140 px |
| Header | Вертикальный padding 12 px; высота sticky состояния в inline CSS 68.1875 px |

Из разных максимальных ширин нельзя сделать вывод, что вся страница имеет ровно одну общую ширину. Финальная реализация методички должна использовать устойчивый адаптивный каркас для длинной кириллицы, а не буквально копировать Elementor span-правила на любой экран.

## Hero — точный способ формирования фона

**В live demo фон hero создан runtime mesh-gradient эффектом и CSS overlay. Это не растровая иллюстрация.**

DOM содержит `data-pix-background-effect="mesh-gradient"` и следующие параметры:

| Параметр | Значение |
|---|---|
| Color 1 | `var(--e-global-color-pixDynamicBackground)` = white |
| Color 2 | `var(--e-global-color-pixPrimaryColor)` = `#155DFC` |
| Color 3 | `var(--e-global-color-pixDynamicGray200)` = `#E4E4E7` |
| Color 4 | Dynamic background = white |
| Speed | 1 |
| Distortion | 0.5 |
| Swirl | 0.4 |
| Scale | 1 |
| Offset X / Y | 0.5 / 0.5 |
| Grain mixer / overlay | 0 / 0 |
| Effect z-index | -1 |

Под эффектом CSS задаёт серую основу `#E4E4E7`. Над эффектом присутствует `linear-gradient(90deg, #FAFAFA 20%, transparent 100%)`. Поэтому в левой части за текстом остаётся почти белый фон, а синее движение сильнее заметно справа.

В методичке допустима собственная реализация этого подтверждённого программного эффекта. Статический CSS градиент сохраняет направленность и цвета, но не воспроизводит исходный shader и его временное движение. Называть его точной копией анимации нельзя.

### Геометрия hero

- Radius: 16 px.
- Border: 1 px gray 200.
- Padding на desktop: 70 px сверху/снизу, 50 px слева/справа.
- Вертикальный gap: 20 px.
- Выравнивание содержимого: к левому краю.
- Заголовок: line-height 1.155; существующий utility `h3` задаёт основной desktop размер.
- Search widget: width/max-width 100%; собственная граница 1 px gray 200.
- Внутри поиска есть настоящие input и button; это не декоративное поле.
- Popular Searches: горизонтальная группа, gap 15 px.

### Адаптив hero

- При ширине до 1024 px padding становится 30 px; gap 10 px.
- В мобильном media rule radius сбрасывается в 0, остаётся нижняя граница; padding 40 px по вертикали и 10 px по горизонтали.
- В мобильном rule заголовок равен 36 px.

У методички выбранные пороги и мобильные поля могут отличаться ради читаемости длинного русского заголовка. Это адаптация, а не наблюдение о Dribbble.

## Popular Articles

CSS задаёт три колонки с gap 40 px. Внутри каждой группы — заголовок категории и список текстовых ссылок, завершённый View more. Это отличает группу статей от большой рекламной плитки: набор ссылок можно быстро просмотреть глазами.

При ширине до 1024 px соответствующая сетка переходит в одну колонку. В мобильных правилах — gap 20 px и padding 20 px. Для сайта с четырьмя или шестью заданиями следует заполнять доступное пространство по реальному количеству, чтобы не оставлять пустую третью колонку в режиме ПА.

В исходнике присутствуют старые стандартные Elementor Roboto/Roboto Slab и базовые цвета. Они являются дефолтами kit, но фактические pixfort шрифты и цвета используют другую систему. Нельзя выбирать Roboto только потому, что он появился первым в CSS.

Опубликованная Dribbble-палитра (`#ECEFF8`, `#010102`, `#A3B1D8`, `#B0B8CC`, `#6C8DEB`, `#2F53F1`, `#57585F`) отличается от live token значений. Это могут быть образцы презентации/эффекта или другая версия темы. Они не заменяют точные роли токенов, найденные в живом исходнике.

### Тёмная тема

Фактический inline CSS переключает background в `#000000`, heading в `#FFFFFF`, gray 50 → `#09090B`, gray 100 → `#18181B`, gray 200 → `#27272A`, gray 300 → `#3F3F46`, gray 400 → `#52525B`, gray 600 → `#A1A1AA`, gray 700 → `#D4D4D8`, gray 800 → `#E4E4E7`, gray 900 → `#F4F4F5`, gray 950 → `#FAFAFA`.

Наличие токенов не доказывает качество контраста любого произвольного блока: темы самой методички надо проверить отдельно.

## Шрифт и локальные файлы

Реальные `@font-face` в HTML — **Inter**. Cloudflare отдаёт `normal.woff2` по языковым поднаборам, в том числе Cyrillic. В исходнике найдены face декларации weight 500/600, URL использует `wght`, поэтому источник поддерживает variable font workflow. Заголовки страницы имеют secondary-font utility.

По поручению главного агента получены публичные оригинальные font asset:

- `public/fonts/inter-latin.woff2`: 48 256 bytes; настоящий WOFF2.
- `public/fonts/inter-cyrillic.woff2`: 18 748 bytes; настоящий WOFF2.
- `public/fonts/Inter-OFL.txt`: SIL Open Font License из официального [google/fonts](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt).

Исходные URL: `https://theme.pixfort.com/cf-fonts/v/inter/5.2.8/latin/wght/normal.woff2` и аналогичный `cyrillic`.

Unicode range Cyrillic: `U+0301,U+0400-045F,U+0490-0491,U+04B0-04B1,U+2116`.

Unicode range Latin: `U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD`.

Остальной ассетный пакет темы, фотографии и чужой логотип не скопированы.

## Статья Installation

Публичная страница подтверждает вложенное вертикальное меню: Overview; группы Getting Started, FAQ, Developers, Changelog с дочерними статьями. В меню присутствует собственное поле поиска. В основной области — H1, категория, текст вступления, выделенный tutorial, checklist, нумерованные шаги, изображения/видео, соседние статьи. Справа — содержание страницы.

Из article CSS:

- Заголовки учебных секций: 24 px desktop, 20 px tablet, 18 px mobile.
- Вводная выделенная карточка: dashed border 1 px gray 200, radius 15 px, padding 30 px.
- Видео и изображения: радиусы 10/16 px.
- Отступы между отдельными частями инструкции часто равны 15 px.

Код и сложные SQL-таблицы в исходном живом article не представлены в нужном для методички объёме. Их оформление не следует выдавать за точную цитату pixfort. Это новые совместимые компоненты, которые обязаны сохранять читаемость, копирование и горизонтальную прокрутку.

## Условия честной приёмки переноса

- Визуальное сравнение можно провести с **живым официальным demo**, снимок которого получен главным агентом.
- С точной исходной Dribbble-картинкой попиксельное соответствие пока не проверяется.
- Собственные тексты, обе квалификации, режимы экзамена, SQL/C# примеры и прогресс сохраняются.
- Сайт методички остаётся Vue. WordPress — источник оформления, не требование к архитектуре.
- Скачать и проверить .NET магазин нужно в его заданном дизайне; его Calibri/цвета не меняются из-за оформления учебной оболочки.
- Для замены партнёрских логотипов/поддержки используются реальные действия методички, без выдуманных социальных доказательств.
- Изученное live demo даёт достаточно подтверждённого визуального материала, чтобы выполнить обоснованную адаптацию сейчас.
