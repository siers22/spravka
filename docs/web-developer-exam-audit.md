## Воспроизведение

```bash
bash examples/ConferencePortal/bin/podman.sh up
npm run check:web
python3 scripts/package-web-course.py
npm run check
VITE_BASE_PATH=/spravka/ npm run build
npm run check:pages -- /spravka/
```

Для полной проверки сайта внутри контейнера:

```bash
podman build -f scripts/Containerfile.guide-check -t localhost/spravka-guide-check:dev .
podman run --rm -v "$PWD:/work" -w /work localhost/spravka-guide-check:dev \
  sh -c 'npm run check && VITE_BASE_PATH=/spravka/ npm run build && npm run check:pages -- /spravka/'
```

Портал оставлен на `http://127.0.0.1:8087/`. Production-предпросмотр методички — `http://127.0.0.1:4173/spravka/`, контейнер `spravka-guide-preview`. Остановить портал: `bash examples/ConferencePortal/bin/podman.sh down`. Удалить только контейнер предпросмотра: `podman rm -f spravka-guide-preview`. Том портала сохраняется.

## Практические границы

Матрица `examples/ConferencePortal/docs/requirements.md` покрывает восемь опубликованных групп на 75 баллов. Это не документ выставления оценки: подробные закрытые аспекты неизвестны, вариативная часть на дополнительные 25 баллов отсутствует.

GIMP не запускался, WebP подготовлены программно. Методичка объясняет самостоятельные действия GIMP, а не выдаёт их за выполненную здесь работу. SVG показывает учебную схему; экспорт ER из собственной MySQL через Workbench описан для студента. Настоящие коммиты экзаменационного дня студент делает сам; история не подделана.

Основная инструкция запуска на площадке — обычный PHP/MySQL с её адресами и правами. Контейнеры — среда разработки и проверки здесь. Локальный Windows/Open Server в этой работе не запускался; переносимый вариант не требует контейнерной сети и включает `config.example.php`.
