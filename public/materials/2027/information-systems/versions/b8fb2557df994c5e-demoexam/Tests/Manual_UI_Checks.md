# Проверка через интерфейс

Эти сценарии позволяют проверить полный путь через WPF. Автоматические проверки основной логики находятся в DemoExam.Checks.exe.

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Обязательные поля | Нажать «Войти» без логина или пароля | Сообщение о необходимости заполнить оба поля. |
| Пазл | Ввести admin/admin, поменять местами два фрагмента и собрать образец | Правильно собранный пазл позволяет войти. |
| Администратор | Войти admin/admin с правильным пазлом | Сообщение «Вы успешно авторизовались», рабочий стол администратора. |
| Новый пользователь | Нажать «Добавить нового», ввести test/student, роль «Пользователь», сохранить | Пользователь появляется в списке. |
| Повторный логин | Повторно добавить test с любым паролем | Сообщение, что пользователь с таким логином существует. |
| Блокировка | Выйти; для test три раза ввести неправильный пароль и нажать «Войти» | На третьей попытке «Вы заблокированы. Обратитесь к администратору». |
| Сохранение блокировки | Перезапустить WPF и ввести правильный пароль test/student | Сообщение о блокировке; вход закрыт. |
| Разблокировка | Войти администратором, выбрать test, снять «Заблокирован», сохранить с пустым паролем | Блокировка снята, старый пароль работает. |
| Ошибки пазла | Для test/student три раза нажать «Войти» с неправильным пазлом | Учётная запись снова блокируется. |
| Права | Войти user25/user123 с правильным пазлом | Открывается рабочий стол пользователя с двумя его заметками; управления пользователями нет. |
| Изменение | Администратор меняет test на student и пароль на newpass | Старый логин перестаёт работать, новый student/newpass работает. |
| Поиск | Ввести в поиске несуществующий логин | Под таблицей сообщение «Пользователи не найдены…». |
| Стоимость | Открыть вкладку «Стоимость заказов» | Материалы 9974,28; операции 4400,00; себестоимость 14374,28; продажа 26828,00. |
| Возврат ко входу | Нажать «Выйти» или закрыть рабочий стол | Снова окно входа, пароль очищен, пазл перемешан. |

Не проводи сценарий трёх неверных входов на admin: это единственный исходный администратор. Создай для проверки отдельную учётную запись.
